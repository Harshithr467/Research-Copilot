# Elasticsearch Index Schema: `research_papers`

This document outlines the structure of the `research_papers` index used in our research engine backend.

## Field Definitions

| Field | Type | Description |
| :--- | :--- | :--- |
| `title` | `text` | The title of the research paper. Optimized for full-text search. |
| `content` | `text` | The main body text of the paper. Optimized for full-text search and highlighting. |
| `embedding` | `dense_vector` | A 384-dimension numerical representation of the paper's content. |
| `metadata` | `object` | Container for structured information (author, year, source, page). |

### Detailed Metadata Fields
- `metadata.author`: (Keyword) The primary author or list of authors.
- `metadata.year`: (Integer) Publication year, used for filtering and sorting.
- `metadata.source_file`: (Keyword) The filename or path of the original document.
- `metadata.parent_id`: (Keyword) Stable ID for the uploaded document.
- `metadata.chunk_id`: (Integer) Chunk number inside the uploaded document.
- `metadata.page_number`: (Integer) Original PDF page number for page-aware citations.

## Understanding Text vs. Vectors

Our search engine uses a **Hybrid Search** approach, combining traditional keyword matching with modern semantic search.

### 1. Text Fields (`title`, `content`)
- **How they work:** Elasticsearch "analyzes" these fields by breaking them into individual words (tokens).
- **Use case:** Finding exact matches, specific names, or phrases (e.g., searching for "Transformer" or "Attention Is All You Need").
- **Strengths:** Precision for known terms.

### 2. Vector Field (`embedding`)
- **How it works:** This field stores a dense vector, a list of 384 numbers generated by an embedding model that captures the *meaning* of the text.
- **Use case:** **Semantic Search.** Finding papers that are conceptually related even if they don't share the same keywords.
- **Similarity:** We use **Cosine Similarity** to find vectors that "point" in the same direction in high-dimensional space.
- **Strengths:** Handles synonyms and conceptual queries (e.g., a query for "neural machine translation" can find papers about "sequence-to-sequence models").
